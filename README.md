# Birthday website

Static site, hosted free with GitHub Pages.

## Deploy
1. Create a new repo on github.com (name e.g. `birthday`). Public is needed for free Pages.
2. Upload everything in this folder (index.html, .nojekyll, assets/) to the repo root.
3. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4. After ~1 minute the site is live at https://YOUR-USERNAME.github.io/REPO-NAME/
